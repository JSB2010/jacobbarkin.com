# Jacob Barkin Portfolio

A modern, responsive portfolio website built with **Next.js 15**, **Tailwind CSS 4**, and **OpenNext**, deployed to **Cloudflare Workers**.

## 🚀 Quick Start

For detailed setup instructions, see [DEVELOPMENT.md](./DEVELOPMENT.md).

```bash
git clone https://github.com/JSB2010/jacobbarkin.com.git
cd jacobbarkin.com
npm install
npm run dev
```

## ✨ Metrics

-   **Performance**: 95+ Lighthouse Score
-   **Architecture**: Serverless SSR on the Edge
-   **Database**: Cloudflare D1 (SQLite)
